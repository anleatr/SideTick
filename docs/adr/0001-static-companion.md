# ADR-0001：静态 Windows 桌宠

状态：已采用；完整平台验收待补充。

## 背景与决定

用户要求停止头像对一般键鼠活动的响应，降低 CPU 占用，移除相关源码与依赖，同时保留计时、拖动、缩放和托盘操作。

复用猫咪 PNG 封面和计时模型，使用 Win32 layered windows 与 GDI 按需绘制。不保留 Live2D、GPUI、Raw Input、音频、插件及对应依赖。相较于只关闭动画，单一应用减少维护范围；代价是放弃模型切换、插件、原设置 UI 和 macOS 支持。当前只有中文 UI。

全局交互仅保留 Ctrl+Alt+L。Days 表示经过的自然日期；Hours 为累计开启计时的时长，显示一位小数。面板采用透明外沿、半透明圆角主体及开关按钮，托盘保留大小、透明度、置顶和退出操作。

直接依赖复用既有固定版本：windows 提供系统 API，image 提供 PNG 与缩放，serde/serde_json 提供序列化，atomic-write-file 提供原子写入。未新增通用依赖。Windows 模块封装系统 API 与绘制；计时模型不依赖窗口类型。

## 数据与源码

保留环境隔离及系统标识，新状态为 personal-state.json，不导入旧开发状态。旧源码移除前已备份并校验；备份和构建缓存不进入 Git。保留上游发布历史，SideTick 未发布功能只维护一条双语摘要。

## 验收

静态版此前已完成人工面板、热键、滚轮和重启检查；主工程迁入后五项测试与静态检查通过。这不替代未来变更后的复验。

完整 DPI/系统版本矩阵、八小时 soak、睡眠期间计时语义专项验证和可分发安装包尚未完成。资产发布前仍需核对头像原始许可与署名；现有 LICENSE 不能替代单项资产来源核对。
